# Changelog

## 1.0.0 - 2026-10-28

- Introduced EpisodeFlow desktop GUI with dark/light themes, 16 interface languages, and branded icon.
- Added filename-only episode detection and customizable templates.
- Added preview, collision-safe batch rename, CSV export, and last-batch undo.
- Added tests for the 161 example filenames.
- Added GitHub Actions Windows EXE build and versioned release packaging.

- Added localized developer credit **@cumaduran** and clickable GitHub profile URL in the application.
- Added manual GitHub Actions release publishing with version input, SHA-256 checksums, and EXE downloads.
